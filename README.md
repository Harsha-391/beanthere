# BEAN THERE ?? — Web Application

A grounded, open-air cafe chain website in Jaipur built with Next.js, React, and Tailwind CSS.

## Features
- **3 Jaipur Outlets**: Pratap Nagar, Jagatpura (Velvet), and Mansarovar (Tritiya)
- **Authentic Jaipur Menu & Real Pricing**: Filterable menu with Jain options and visit cost estimator
- **Live Instagram Reels Embeds**: Integrated live video embeds from `@beantherebharat`
- **Table Reservation System**: Free instant table & pod booking system
- **Weekend Jam Sessions**: Acoustic unplugged lineup & performer registration

## Tech Stack
- Framework: Next.js (App Router)
- Styling: Tailwind CSS
- Icons: Lucide React
- Visuals: Custom SVG Laurel Branch Line Art & Monogram

## Local Setup
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
